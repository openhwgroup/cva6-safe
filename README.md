# cva6-safe
A dual-core lockstep (DCLS) subsystem for the CVA6.  Also supports dual-core asymmetric multi-processing (AMP) when lockstep in not needed.
The hardening of cache memories against single event upsets (SEU) is also on the agenda.
Expect source code publication in 1Q2026.
